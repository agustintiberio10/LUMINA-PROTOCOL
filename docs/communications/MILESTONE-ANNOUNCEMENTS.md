## Formatting Guidelines

1. **Tone**: Professional, confident, factual. Avoid hype language ("revolutionary", "game-changing").
2. **Structure**: Lead with the news, provide context, include specifics, end with next steps.
3. **Links**: Always include verifiable links to contracts, docs, and audits.
4. **Numbers**: Include concrete metrics wherever possible (TVL, capacity, dates).
5. **Approval**: All milestone announcements require sign-off from [ROLE] before publication.
6. **Timing**: Coordinate publication across all channels within a 5-minute window.
