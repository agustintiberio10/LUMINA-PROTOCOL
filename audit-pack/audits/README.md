## Convention

Files named: `YYYY-MM-DD-<audit-name>.md`

Each audit file should include:

- Date + scope
- Methodology (who/how)
- Scores per dimension
- Findings (severity: Critical / High / Medium / Low)
- Recommendations
- Verdict
- Linked fix sprints (cross-ref to `audit-pack/sprints/`)
